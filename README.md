# 📊 Dashboard de Vendas – Xbox Game Pass Subscriptions

Este projeto apresenta uma dashboard interativa desenvolvida no **Microsoft Excel** para análise de vendas de assinaturas de serviços de jogos, como **EA Play Season Pass**, **Minecraft Season Pass** e **Xbox Game Pass**.

---

## 🎯 Objetivo

Fornecer uma visualização clara, rápida e intuitiva dos dados de vendas, permitindo acompanhar o desempenho e apoiar a tomada de decisões.

---

## 📅 Período de Análise

- **Intervalo:** 01/01/2024 a 31/12/2024  
- **Última atualização:** 23/06/2026  

---

## 📌 Indicadores Principais

- **EA Play Season Pass**
  - Valor total consolidado das vendas deste serviço.

- **Minecraft Season Pass**
  - Soma das vendas relacionadas ao produto Minecraft.

- **Xbox Game Pass**
  - Visualização comparativa entre assinaturas ativas ("Yes") e não ativas ("No"), destacando o desempenho geral.
---

## 🔎 Funcionalidades

- 🎛️ **Filtros interativos**
  - Anual
  - Mensal
  - Trimestral

- 📊 **Visualização gráfica**
  - Gráfico de barras para comparação de status das assinaturas

- 🎨 **Interface amigável**
  - Layout limpo com destaque para KPIs principais

---

## 🛠️ Tecnologias Utilizadas

- Microsoft Excel
  - Tabelas Dinâmicas
  - Segmentação de Dados (Slicers)
  - Gráficos Dinâmicos
  - Formatação Condicional

---

## 📈 Benefícios

- Melhor visualização dos dados
- Acompanhamento rápido de desempenho
- Facilidade na análise sem necessidade de ferramentas avançadas
